# v1 build vs later

Agents are implementing the v1 loop in parallel on the web app + shared Supabase.

## Shipping in this pass

- Safety plan builder, emergency contacts, coping toolkit, “what worked for me”, grounding reminder cadence
- Unlimited + adaptive check-ins, weekly consistency (missed day does not wipe), show-up language
- Rateable / dismissible clinician alerts with low · moderate · high · urgent
- Office hours, pre-session briefing, life-event timeline, extra symptom fields

## Designed, not bolted on

Privacy/consent v2 lives in `docs/privacy-consent-v2.md`. Do not add extra consent checkboxes until that doc is accepted.

## Not this pass (product / data still needed)

- Evidence-based modality layer (CBT / DBT / ACT / BA) — needs datasets
- How the product insists on human support vs becoming the only support
- Cultural / language / belief-sensitive replies
- PNC questionnaires, readings, resource library expansion
- Full multi-week ML pattern engine, menstrual-cycle insights beyond opt-in field
- Symptom graphs beyond the briefing snapshot
